# Example submission

The baseline SHA-256 circuit will be built here (milestone M3 in `../../PLAN.md`), in the
layout every submission uses:

| File | What |
|---|---|
| `circuit.kmb` | The circuit that is verified |
| `meta.json` | Name, authors, description, problem id, kind |
| `build.py` | Optional: how the circuit was generated. Never run by CI. |
